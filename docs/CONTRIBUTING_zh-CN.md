# 为 XrayFA 做贡献

[English](../CONTRIBUTING.md)

欢迎反馈问题、修复缺陷、完善翻译和文档。

## 反馈问题

先查看 [已有 Issue](https://github.com/Q7DF1/XrayFA/issues)。反馈时请说明应用版本、系统版本、复现步骤和预期结果。可以附日志或截图，但请移除订阅地址、凭据和个人信息。

提出功能建议时，说明使用场景和希望改进的地方即可。

## 提交修改

Fork 仓库，需要构建时参考 [构建说明](README_zh-CN.md#从源码构建)。每个 PR 尽量聚焦一个问题，提交到 `main`，简单说明改了什么以及原因。

提交前检查受影响的功能，并简述验证方式。文档修改检查内容和链接即可；界面修改可以附截图，方便查看效果。

请保持友善交流。贡献适用项目的 [Apache-2.0 许可证](../LICENSE)。
