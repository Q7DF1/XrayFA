# Contributing to XrayFA

[简体中文](docs/CONTRIBUTING_zh-CN.md)

Bug reports, fixes, translations, and documentation improvements are welcome.

## Report an issue

Search [existing issues](https://github.com/Q7DF1/XrayFA/issues) first. Include the app version, OS version, reproduction steps, and expected behavior. Logs or screenshots are helpful; remove subscription URLs, credentials, and personal information.

For feature requests, describe the use case and what you would like to improve.

## Submit a change

Fork the repository and follow the [build instructions](README.md#build-from-source) if needed. Keep each pull request focused and submit it against `main`, explaining what changed and why.

Check the affected functionality before submitting and briefly describe how you tested it. For documentation changes, checking the content and links is enough. Include screenshots for UI changes when helpful.

Please keep discussions respectful. Contributions follow the project's [Apache-2.0 license](LICENSE).
